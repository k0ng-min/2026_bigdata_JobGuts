# 설명 계층 경계

추천 규칙, 지표, 근거 공고는 분석·조회 계층이 결정한다. 언어 모델 계층은 이미 결정된 결과를 설명하는 선택적 계층이며, 추천을 재계산하거나 근거를 생성하지 않는다.

현재 `src/llm/`에는 제공자 독립 요청·응답 계약과 결정적 fake provider만 있다. 실제 GLM 통합은 별도 최종 단계에서 provider 구현으로 추가한다. 그 단계 전까지 API 키, SDK 의존성, HTTP 요청, 모델 호출을 추가하지 않는다.

환경 변수 이름, 인증 방식, 모델 이름, 재시도 정책은 실제 통합 승인 시 확정한다.

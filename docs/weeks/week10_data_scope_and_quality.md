# 10주차 데이터 범위와 품질 점검

## 목표

분석 데이터 파일 하나를 선정하고 공고 구조·중복·결측·직무·경력 상태를 확인한다. 기술 정규화, Apriori, GLM 연결은 구현하지 않는다.

| 역할 | 작업 | 완료 기준 |
| --- | --- | --- |
| 데이터 | 파일 버전, 로더, 스키마·중복·결측 점검 | 파일명·버전·행 수와 중복 제거 기준 기록 |
| 정규화 | `final_techs`/`hard_skills` 결측·차이, 원문 표본 | 출발 기술 필드와 빈 목록 정책 확정 |
| 분석 | 분석 단위·직무·경력·세그먼트 설계 | Apriori 입력과 제외 기준 정의 |
| 서비스 | 질의·응답·필터·근거 공고 요구사항 | 빈 결과 처리 포함한 스키마 초안 |

## 산출물

- `src/ingestion/` 로더·스키마 검증·품질 집계
- `configs/data_scope.*` 데이터·직무·경력·중복 기준
- `artifacts/week10_data_quality_summary.*` 행 수, ID 누락, 중복, 기술 필드 차이
- `artifacts/week10_raw_text_samples.*` 직무·경력 원문 대조 표본
- `docs/weeks/week10_actual_results.md` 실제 수치·문제·다음 작업

## 검증 및 인계

동일 입력에서 동일 요약을 재현한다. `source + job_id` 중복과 본문 의심 중복을 분리하고, 모호한 경력은 `needs_review`로 남긴다. 확정 공고 집합과 데이터 범위를 11주차에 전달한다.

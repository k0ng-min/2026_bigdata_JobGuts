# 13주차 규칙 조회와 서비스 통합

## 목표

보유 기술과 필터에 맞는 규칙 및 실제 근거 공고를 반환하는 흐름을 만든다. GLM 실제 연결은 하지 않는다.

| 역할 | 작업 | 완료 기준 |
| --- | --- | --- |
| 데이터 | 근거 조회용 메타데이터 제공 | 공고 식별자와 원문/요약 일관성 |
| 정규화 | 사용자 입력 기술 정규화 | 미등록·모호 입력 정책 |
| 분석 | 규칙과 근거 공고 연결 | 규칙에서 공고 식별자로 추적 가능 |
| 서비스 | API/UI, 빈 결과·재검색·추가 질문 흐름 | 사용자 흐름 통합 테스트 통과 |

## 산출물과 응답 규칙

- `src/retrieval/`, `src/service/`, mock만 둔 `src/llm/`
- `artifacts/week13_service_scenarios.*`, `docs/weeks/week13_actual_results.md`

응답에는 추천 기술, 지표, 적용 직무·경력 필터, 근거 공고를 넣는다. 표본 부족·규칙 없음·미등록 입력은 상태와 다음 행동을 제공한다. 범위를 넓혔다면 변경 범위를 명시한다. GLM 없이도 모든 통합 테스트가 통과해야 한다.
